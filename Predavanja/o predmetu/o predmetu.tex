\begin{frame}{Cilj kolegija}
\begin{itemize}
  \item Izraditi \textbf{full-stack} web aplikaciju: backend + frontend + baza
  \item Razumjeti \textbf{arhitekturu} web sustava i trade-offe
  \item Ovladati \textbf{API dizajnom} i modeliranjem podataka
  \item Implementirati \textbf{autentikaciju} (JWT) i \textbf{autorizaciju} (role/ownership)
  \item Izgraditi SPA frontend: \textbf{Vue 3}, routing, state management, UX discipline
  \item Uspostaviti \textbf{workflow}: Git, commitovi, testiranje, CI i deploy
\end{itemize}

\vspace{0.4em}
\textbf{Ishod:} student može samostalno izraditi, testirati i deployati manju web aplikaciju.
\end{frame}

\begin{itemize}

\vspace{0.4em}

\begin{frame}{Zašto je ova tema dobra za učenje?}
\begin{itemize}
  \item Prirodno sadrži \textbf{role} i \textbf{ownership} - admin vidi sve, klub samo svoje
  \item Ima \textbf{workflow} i vremenska poslovna pravila - realan backend, ne samo CRUD
  \item Relacije i constrainti - realan rad s bazom
  \item Frontend je zanimljiviji: tablice, filteri, statusi, onemogućeni gumbi po fazi
  \item Obrana po kodu je jasna: može se postaviti \textbf{precizno pitanje} i provjeriti razumijevanje
\end{itemize}

\begin{frame}{Arhitektura aplikacije}

\textbf{Frontend (SPA)} komunicira s backendom preko \textbf{REST API-ja}. Backend implementira:
\begin{itemize}
  \item autentikaciju (JWT) i autorizaciju (role/ownership)
  \item poslovna pravila i rad s bazom
  \item dokumentaciju API-ja (OpenAPI/Swagger)
\end{itemize}

\vspace{0.4em}
Baza je \textbf{jedini izvor istine} za podatke.

\vspace{0.4em}
Frontend je \enquote{glup} za pravila - backend je autoritet. UI može sakriti opcije, ali backend \textbf{mora zabraniti}.
\end{frame}

Demonstracija funkcionalnosti, pregled repozitorija i \textbf{ključnih dijelova koda}, pitanja o odlukama i edge caseovima. Moguća mini promjena uživo: dodaj polje, migraciju, prilagodi DTO/UI.

\vspace{0.6em}
\begin{block}{Tipična pitanja}
\begin{itemize}
  \item Gdje provjeravaš ownership?
  \item Kako backend zabranjuje izmjene nakon roka?
  \item Zašto je status code 401/403/409/422?
  \item Gdje i kako hendlaš 401 na frontendu?
\end{itemize}
\end{block}

\begin{frame}{Testiranje}
Test nije \enquote{još jedan zadatak} - to je \textbf{osiguranje} da pravila vrijede. Fokus testova u ovom projektu:

\begin{itemize}
  \item Autentikacija - login/refresh
  \item Autorizacija - role/ownership
  \item Rokovi - prije prelim / između / nakon final
  \item Unikatan constraint - nema duple prijave
\end{itemize}

\vspace{0.4em}
Na obrani ću vas pitati \textbf{što točno test pokriva} i \textbf{zašto je to bitno}.
\end{frame}

% ------------------------------
\begin{frame}{Deploy: što znači \enquote{radi u produkciji}}
Deploy nije samo \enquote{imam URL}. Morate razumjeti:

\begin{itemize}
  \item Env varovi i tajne - JWT secret, DB URL
  \item CORS - frontend domena $\leftrightarrow$ backend
  \item Migracije u produkciji - alembic upgrade
  \item Error logging - što logiramo, što ne
\end{itemize}

\vspace{0.4em}
Koristit ćemo moderni PaaS - Railway ili Render.
\end{frame}

% ------------------------------
\begin{frame}{Akademska čestitost i AI alati}
AI možete koristiti za pomoć, ali na obrani morate \textbf{razumjeti i objasniti svoj kod}. Kopirani kod bez razumijevanja se vidi odmah na usmenom.

\vspace{0.4em}
Ako koristite vanjske snippete, morate znati:
\begin{itemize}
  \item Gdje su rizici za sigurnost
  \item Što se događa u edge caseovima
  \item Kako to testirate
\end{itemize}
\end{frame}

% ------------------------------
\begin{frame}{Kako učiti ovaj kolegij}
\begin{itemize}
  \item Svako predavanje: pogledaj diffove, reproduciraj korake u svom repou
  \item Ne gomilaj dugačke sesije - radi \textbf{malo i često}
  \item Debugging rutina:
    \begin{itemize}
      \item pročitaj error, izoliraj uzrok, napravi najmanji repro
      \item provjeri request/response - status code, payload
      \item koristi logove i devtools
    \end{itemize}
  \item Kad zapne: pokaži \textbf{konkretan problem} - log, request, commit
\end{itemize}
\end{frame}
